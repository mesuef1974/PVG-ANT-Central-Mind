Status: COMPLETED

## Purpose

Extend the Research Memory Graph from finite residue characters and arithmetic-progression observables to the primitive/imprimitive distinction, conductor, Gauss sums, completed Dirichlet L-functions, and the functional-equation dependency boundary.

## Core objects

For a Dirichlet character `chi` modulo `q`:

- `chi` is primitive when it is not induced from a character of any proper divisor of `q`.
- Its conductor `f` is the least modulus of a primitive character `chi*` inducing it.
- The Gauss sum is

  `tau(chi) = sum_{a mod q} chi(a) exp(2 pi i a/q)`.

- Its parity `a in {0,1}` is defined by

  `chi(-1)=(-1)^a`.

For primitive `chi`, the completed function is

`Lambda(s,chi)=(q/pi)^((s+a)/2) Gamma((s+a)/2)L(s,chi)`.

The standard functional equation has the form

`Lambda(s,chi)=epsilon(chi)Lambda(1-s,conjugate chi)`

with `|epsilon(chi)|=1` and, under the standard normalization,

`epsilon(chi)=tau(chi)/(i^a sqrt(q))`.

## ANT to PVG translation

The finite arithmetic part translates as follows:

1. Decode a PVG valuation vector to its integer.
2. Reduce modulo `q`.
3. Apply the character phase.
4. Apply a finite Fourier transform to obtain the Gauss sum.

The conductor becomes the minimal residue-channel modulus carrying the same phase observable.

This finite layer is exact. The following are not generated by it:

- analytic continuation,
- the Gamma factor,
- the global functional equation,
- the zero distribution,
- GRH.

Therefore the translation class changes at the finite-to-analytic interface:

- character values and induction: exact finite data;
- Gauss sums: exact finite Fourier data;
- completed L-functions: partial/diagnostic translation;
- functional equation: known analytic theorem requiring an external certificate.

## Primitive and imprimitive distinction

If `chi` modulo `q` is induced from primitive `chi*` of conductor `f`, then the associated L-series differs by finitely many Euler factors:

`L(s,chi)=L(s,chi*) product_{p|q, p not dividing f}(1-chi*(p)p^{-s})`.

This correction is exact where the Euler products are justified, but it does not promote finite residue data to analytic continuation.

## Numerical examples

The executable verifier checks:

- a quartic primitive character modulo `5`;
- a primitive quadratic character modulo `8`;
- an imprimitive character modulo `12` induced from conductor `4`.

Computed Gauss sums:

- modulo `5`:

  `tau = -1.175570504584946 + 1.9021130325903073 i`

  `|tau| = 2.23606797749979 = sqrt(5)` numerically.

- modulo `8`:

  `tau = 2.8284271247461903 - 3.33e-16 i`

  `|tau| = 2.8284271247461903 = sqrt(8)` numerically.

For the modulo-5 character, parity is odd and the normalized root number has modulus `1`.
