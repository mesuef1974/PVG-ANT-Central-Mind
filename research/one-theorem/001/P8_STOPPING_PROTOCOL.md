# P8 Stopping Protocol - pre-registered decision tree

**ID:** P8-STOPPING-PROTOCOL-001 (Stage Review 001 PR-A). Recorded before any
packet is sent; outcomes are terminal, not renegotiable.

```text
1. Known result
   -> close as known_classical_consequence;
      extract the PVG discovery lesson; no renaming of the result.
2. Known machinery / new specialization
   -> close as new application of a general known theorem;
      claim ceiling fixed accordingly.
3. Repairable proof defect
   -> exactly one named repair, then one re-referee round.
4. Structural proof defect
   -> negative certificate; no rescue attempts.
5. Novel result
   -> record PVG materiality verdict separately per role
      (observable / formula / local factors / proof steering /
      generalization); only then a publication-readiness review.
```

Each branch records exactly one terminal theorem classification. No branch
permits reopening internal improvement of the packet. Zero RH progress; zero
GRH progress; no secured path.

**Classification:** Governance / Pre-registered decision protocol. No mathematical claim.
