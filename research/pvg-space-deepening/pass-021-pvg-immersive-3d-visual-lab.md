# PASS-021 — PVG Immersive 3D Visual Lab

## الهدف

ترقية المعمل البصري من لوحة تحليل ثنائية الأبعاد إلى معمل مشهدي ثلاثي الأبعاد يوضح البنية الهندسية والديناميكية لـ PVG دون تحويل النتائج المنتهية إلى ادعاءات عامة.

## نطاق النسخة الأولى

- حدود الأوليات: `100, 150, 200`.
- أعماق الديناميكا: `0..5`.
- مستويات الفضاء الأساسية: `Omega=1..8`.
- صفحة محلية ذاتية الاكتفاء بلا مكتبات أو اتصالات خارجية.
- محرك إسقاط ثلاثي الأبعاد مبني على Canvas مع كاميرا دوران وتكبير وتحريك.

## المشاهد

1. **فضاء PVG**: النقاط `(a,b,c)` والأعداد `2^a 3^b 5^c` ومستويات `Omega=a+b+c`.
2. **الهوية الباسكالية**: خلية متحركة تحقق `2g + 3g = 5g` على مستوى ثابت.
3. **أحواض الجذب**: عقد المحاور الطرفية وسحب من وجوه البدء، مع إظهار الحصري والمشترك.
4. **كوكبة التداخل**: رسم موزون ثلاثي الأبعاد، مع إبراز المحور 5 والحافة `{5,7}` داخل النطاق.
5. **الاستقرار عبر العمق**: ست طبقات لـ `D=0..5` تفصل غير المحسوم والأحادي والمتعدد.
6. **توسيع حد الأوليات**: مقارنة مكانية بين `L=100,150,200` وإبراز الظهور الأول للمحاور والبنى الجديدة.
7. **تتبع وجه**: رسم طبقي مباشر لأي وجه يحدده المستخدم.

## محرك الحساب

يستخدم المعمل مؤثر الوجه الجمعي:

\[
T(S)=\{\operatorname{supp}(a+b):a,b\in S,\ a<b\}.
\]

ويعيد داخل المتصفح بناء:

- وجوه البدء؛
- طبقات الوصول؛
- المحاور الطرفية؛
- أحواض الجذب؛
- توقيعات النهايات؛
- أوزان التداخل؛
- والمكونات المتصلة.

## التحقق

- الصفحة ذاتية الاكتفاء.
- فحص JavaScript بواسطة Node.
- إعادة إنتاج نتائج الحدود 100 و150 و200.
- التحقق من الحالتين `{37,97}` و`{61,73}` عند العمق الخامس.
- التحقق من وجود المشاهد السبعة ومحرك الكاميرا والتفاعل.

- تفسير الاستمرار خارج النطاق: `OPEN`.

## السقف العلمي

لا يقدم المعمل مبرهنة انتهاء عامة، أو ثباتًا تقاربيًا، أو مركزية عامة للمحور 5، أو استحالة لتوقيع غير مرصود، أو تقدمًا في غولدباخ أو RH أو GRH.
