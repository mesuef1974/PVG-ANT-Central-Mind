## Question

After fixing the same small-prime residue information at the center `x`, can a neighborhood built only from divisibility of `x+k` by those same primes contain additional information distinguishing primes from composites?

## Exact answer

No.

Let `L` be a finite set of primes and `K` a finite set of integer offsets not containing `0`. Define the local divisibility field

\[
E_{L,K}(x)=\bigl(1_{\ell\mid x+k}\bigr)_{\ell\in L,\,k\in K}.
\]

For every `ell in L` and `k in K`,

\[
\ell\mid x+k
\iff
x\equiv-k\pmod\ell.
\]

Therefore `E_{L,K}(x)` is a deterministic function of the center residue vector

\[
R_L(x)=(x\bmod\ell)_{\ell\in L}.
\]

Consequently, if two centers `x` and `y` satisfy

\[
x\equiv y\pmod\ell\qquad(\ell\in L),
\]

then

\[
E_{L,K}(x)=E_{L,K}(y).
\]

Equivalently, writing

\[
W_L=\prod_{\ell\in L}\ell,
\]

we have

\[
x\equiv y\pmod{W_L}
\Longrightarrow
E_{L,K}(x)=E_{L,K}(y).
\]

This is an `IDENTITY / PROVED` statement and requires no statistical experiment.

## Information-theoretic formulation

Because the neighborhood field is a deterministic function of the matched residue vector,

\[
I\bigl(\text{prime-label};E_{L,K}(x)\mid R_L(x)\bigr)=0.
\]

This line is an interpretation of the exact determinism, not a new probabilistic theorem about prime distribution.

## Example

Take

\[
L=\{3,5,7\},\qquad K=\{-4,-2,2,4\}.
\]

If

\[
x\equiv y\pmod{105},
\]

then `x+k` and `y+k` have exactly the same divisibility status by `3`, `5`, and `7` at every listed offset. No classifier using only those bits can separate `x` from `y` after the residue class modulo `105` is fixed.

## Prime-power refinement

If the feature records truncated valuations

\[
\min(\nu_\ell(x+k),a_\ell),
\]

then it is determined by

\[
x\bmod \ell^{a_\ell}.
\]

Thus matching only modulo `ell` may leave apparent extra information, but that information is merely unreconciled prime-power residue data. If the center is matched modulo every required `ell^{a_ell}`, the corresponding truncated-valuation neighborhood is again deterministic and redundant.

The following features cannot add information after their generating center residues are fixed:

- local-survival masks relative to those primes;

- truncated valuation fields once the matching includes the corresponding prime powers.

Machine learning cannot overcome this ceiling. Any apparent gain would indicate residue leakage, incomplete matching, range leakage, or implementation error.

## What may still carry additional information

A legitimate experiment must include information not already determined by the matched center residues, for example:

1. divisibility by primes outside the matched set;
2. valuations beyond the matched prime-power depth;
3. exact or censored least-prime-factor sizes above the local bound;
4. primality or compositeness status of selected neighbors, while excluding the center;
5. PVG support statistics of neighbors using factors outside the matched local basis;
6. multi-scale features whose larger scale is evaluated on a genuinely held-out numerical range.

These features may contain additional information, but a positive result would initially be `FINITE-VERIFIED / DIAGNOSTIC`, not a primality criterion.
