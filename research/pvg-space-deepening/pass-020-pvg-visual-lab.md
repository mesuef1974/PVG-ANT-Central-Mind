# PASS-020 — PVG Visual Lab

## الهدف

إنشاء معمل بصري محلي ذاتي الاكتفاء يوحّد نتائج PASS-016 إلى PASS-019، مع فصل صريح بين **المرجع المسجل** و**الحساب الحي المنتهي داخل المتصفح**.

## النطاق

- حدود الأوليات المسجلة: `100, 150, 200`.
- الأعماق: `0..5`.
- عائلتا البدء: الأطلس التراكمي والدفعة الجديدة.
- لا تحميل لمكتبات أو بيانات من الشبكة.

## محرك الديناميكا

لوجه دعم أولي `S` يعرّف الانتقال بواسطة دعوم مجاميع الأزواج:

\[
T(S)=\{\operatorname{supp}(a+b):a,b\in S,\ a<b\}.
\]

تعيد الصفحة بناء وجوه البدء، طبقات الوصول، المحاور الطرفية، أحواض الجذب، توقيعات النهايات، وتداخلات الأحواض. يحفظ التخزين المؤقت نتائج كل ثلاثية `(L,D,mode)`.

## الوحدات البصرية

1. نظرة عامة وتوزيع المخرجات الطرفية.
2. أحواض الجذب مع الحصري والمشترك وعمق الوصول.
3. رسم تداخل الأحواض الموزون.
4. أطلس توقيعات النهايات ورتبها.
5. استقرار العمق المسجل عند `L=100`.
6. مقارنة توسع الحد `100→150→200`.
7. تتبع حي لوجه يحدده المستخدم.
8. لوحة مطابقة الحساب الحي بالمرجع المسجل.

## التشغيل

```powershell
powershell -ExecutionPolicy Bypass -File tools\open_pvg_visual_lab.ps1
```

أو افتح مباشرة:

```text
web/pvg-pareto-explorer/visual-lab.html
```

## التحقق

- الصفحة ذاتية الاكتفاء ولا تستخدم موارد خارجية.
- فحص صياغة JavaScript بواسطة Node.
- إعادة إنتاج الصفوف التراكمية المسجلة عند الحدود الثلاثة.
- إعادة إنتاج إحصاءات الدفعتين الجديدتين.
- تحقق وجود جميع عناصر التحكم والوحدات.

## التصنيف العلمي

- تعريف الانتقال والحسابات داخل النطاق: `EXACT FINITE COMPUTATION`.
- مطابقة نتائج PASS-016..019 المسجلة: `FINITE-VERIFIED`.
- استمرار الأنماط خارج الحدود أو الأعماق المسجلة: `OPEN`.

## السقف

المعمل أداة استكشاف وتدقيق. لا يقدم مبرهنة انتهاء عامة، أو ثباتًا تقاربيًا، أو مركزية عامة للمحور 5، أو تقدمًا في غولدباخ أو RH أو GRH.
