## 1. Purpose

Dataset 003 is an independent confirmatory replication of the exploratory Dataset 002 result. It is not a continuation of model search.

The primary question is:

> Does the frozen past-only Lambda/character/residue-energy model improve held-out prediction of the standardized local prime-count residual over the frozen classical model on a completely new numerical decade?

No Dataset 003 observations may be generated before this protocol is merged into `main`.

## 2. Independent numerical range

The Dataset 003 range is fixed to

```text
10,000,000 <= x < 100,000,000
```

This range is disjoint from Dataset 001 and Dataset 002, which ended below `10,000,000`.

Exact prime and von Mangoldt values must be generated by a deterministic segmented sieve. The implementation may optimize memory and speed but may not change the mathematical sample.

## 3. Window families and deterministic sampling

The three window families are frozen as

```text
h = round(x^(1/2))
h = round(x^(2/3))
h = round(x^(3/4))
```

For each family:

1. start at `x = 10,000,000`;
2. set `h = max(10, round(x^theta))`;
3. form the inclusive window `[x, x+h-1]`;
4. move the next start to the previous end plus one;
5. stop before `100,000,000`;
6. select exactly 160 windows by deterministic evenly spaced indices over the complete non-overlapping list.

The complete lists contain at least 160 windows for every family; the limiting `theta=3/4` family contains 175 windows in this range.

Expected confirmatory sample size:

```text
160 windows x 3 families = 480 windows
```

No random subsampling and no post-hoc window deletion are allowed. A window may be removed only for a documented computational corruption, and any removal invalidates confirmatory status until the protocol is amended and re-frozen before analysis.

## 4. Primary response

For each target window `[x, x+h-1]`, define

```text
P(x,h) = pi(x+h-1) - pi(x-1)
E(x,h) = Li(x+h-1) - Li(x-1)
Y(x,h) = (P(x,h) - E(x,h)) / sqrt(E(x,h))
```

The primary response is `Y(x,h)`, identical in meaning to `li_std_residual` in VRP001.

## 7. Primary hypothesis and statistic

Let

```text
Delta = RMSE(classical) - RMSE(primary candidate)
```

The confirmatory alternative is

```text
H1: Delta > 0
```

The primary uncertainty procedure is a paired block bootstrap over windows, stratified by theta family, with a frozen seed and 10,000 replicates. Each replicate resamples 160 paired observations with replacement inside each family and concatenates the three resampled strata before calculating `Delta`.

Frozen seed:

```text
20260712
```

The reported interval is the percentile 95% interval for `Delta`.

## 8. Promotion rule

Dataset 003 is promoted to `REPLICATED CANDIDATE SIGNAL` only if all conditions hold:

1. overall `Delta > 0`;
2. the paired-bootstrap 95% lower bound is strictly greater than zero;
3. `Delta > 0` separately in each of the three theta families;
4. no data-dependent feature, alpha, window, modulus, lag, or model change occurred;
5. Python and R implementations agree on row counts, response values, predictions, and decision within declared floating-point tolerance.

If conditions 1–2 pass but condition 3 fails, classify:

```text
HETEROGENEOUS EXPLORATORY REPLICATION — NOT PROMOTED
```

If the 95% interval contains zero, classify:

```text
UNRESOLVED IN INDEPENDENT REPLICATION
```

If the 95% upper bound is at most zero, classify:

```text
NEGATIVE INDEPENDENT REPLICATION
```

No alternative success rule may be substituted after results are visible.

## 9. Native residue-class secondary endpoint

A secondary, non-promotional analysis will study

```text
psi(x+h-1; q,a) - psi(x-1; q,a)
```

for reduced residue classes modulo

```text
q in {3,4,5,7,8,11}.
```

For each reduced residue `a`, use the standardized response

```text
Y(q,a;x,h) =
  [psi(x+h-1;q,a) - psi(x-1;q,a) - h/phi(q)]
  / sqrt(h*log(x)/phi(q)).
```

This endpoint is included because characters are native to residue-class prime distribution. It is secondary and exploratory in Dataset 003. It cannot promote the aggregate prime-count signal, and no individual `(q,a)` result may be advertised without multiplicity correction and a later independent protocol.
