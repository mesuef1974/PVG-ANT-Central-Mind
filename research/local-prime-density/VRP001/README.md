```bash

python Dataset001/analysis/build_dataset_001.py
python Dataset001/analysis/analyze_dataset_001.py
python Dataset002/analysis/build_dataset_002.py
python Dataset002/analysis/verify_dataset_002.py

```

- Dataset 001: identical columns and numeric values.
