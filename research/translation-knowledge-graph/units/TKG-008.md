## Purpose

Separate the presentation modulus of a Dirichlet character from its minimal primitive source, and represent induction as preservation of residue-phase data plus a finite set of extra bad-prime axis masks.

## Core definitions

For a character `chi` modulo `q`, the conductor `f` is the least divisor of `q` for which `chi` is induced by a primitive character `chi*` modulo `f`.

```text
primitive  <=> conductor = modulus
induced    <=> conductor < modulus
```

The modulus is therefore not automatically the conductor.

## Examples

```text
principal character modulo 4:
modulus = 4
conductor = 1
primitive source = trivial character modulo 1
extra bad prime = 2

chi4 modulo 4:
modulus = conductor = 4
primitive = true

chi4 presented modulo 8:
modulus = 8
conductor = 4
primitive source = chi4
no newly bad prime, because 2 already divides the conductor
```

## L-function correction

If `chi` modulo `q` is induced by primitive `chi*` modulo `f`, then in the absolute-convergence region:

```text
L(s,chi)
= L(s,chi*) product_{p|q, p not|f} (1-chi*(p)p^{-s}).
```

Thus induction does not merely rename a character. It preserves all good-prime local factors and removes the finite set of newly bad prime axes.

For the principal character modulo 4:

```text
L(s,chi0 mod 4) = zeta(s)(1-2^{-s}).
```

## Twisted Mangoldt coefficients

The logarithmic derivative correction means that the coefficients of

```text
-L'(s,chi)/L(s,chi)
```

agree with the primitive coefficients away from newly bad primes, while all prime-power points on newly bad axes are annihilated.

For the principal character modulo 4:

```text
n=8=2^3  -> coefficient 0
n=9=3^2  -> coefficient log 3
```

## Information preservation and loss

Preserved:

- primitive phase values on good primes;
- conductor and presentation modulus;
- the finite extra bad-prime set;
- all local factors away from that set.

Lost by induction:

- coefficients on newly bad prime-power axes.

Lost after anonymizing axes:

- which primes divide the conductor or modulus;
- which Euler factors were removed;
- the logarithmic weights `log p`.
