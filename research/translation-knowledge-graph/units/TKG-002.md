## Exact ANT algebra

For arithmetic functions `f` and `g`,

```text
(f * g)(n) = sum_{d|n} f(d) g(n/d)
            = sum_{ab=n} f(a) g(b).
```

The committed harness verifies finite instances of:

```text
epsilon * f = f
1 * 1 = tau
1 * id = sigma
mu * 1 = epsilon
mu * log = Lambda
```

Möbius inversion is represented operationally as:

```text
F = 1 * f    <=>    f = mu * F.
```

No pointwise reciprocal is used or accepted as an inverse.

## PVG translation

Let `alpha = nu(n)`. Every divisor `d|n` corresponds exactly to a sub-vector `beta` satisfying

```text
0 <= beta <= alpha
```

coordinatewise, while the complementary factor `n/d` corresponds to

```text
alpha - beta.
```

Therefore Dirichlet convolution becomes a finite complementary-pair sum over the valuation divisor box:

```text
(f * g)(n)
=
sum_{0 <= beta <= alpha}
  f(decode(beta)) g(decode(alpha-beta)).
```

This is an exact reindexing when prime coordinates remain labelled and the integer decoder is retained.

## What the translation preserves

- divisibility order;
- factor-pair complementarity;
- the finite convolution value;
- the product-of-chains structure of the divisor poset;
- box cardinality, hence `tau(n)`;
- Möbius inversion as incidence-algebra inversion;
- local prime-axis factorization for multiplicative functions.

## What it can lose

An anonymized box shape preserves exponent patterns but loses prime identities and arithmetic magnitudes. Consequently it does not determine weighted observables such as `sigma`.

Concrete counterexample:

```text
12 = 2^2 * 3      exponent shape (2,1), sigma(12)=28
18 = 2 * 3^2      exponent shape (2,1), sigma(18)=39
```

The unit therefore distinguishes:

```text
labelled divisor-box geometry  -> exact arithmetic recovery
unlabelled box shape           -> partial combinatorial information only
```

## Numerical example: n = 12

```text
12 = 2^2 * 3
nu(12) = (2,1)
divisors = 1,2,3,4,6,12
box cardinality = (2+1)(1+1) = 6

tau(12) = 6
sigma(12) = 1+2+3+4+6+12 = 28
(mu * 1)(12) = epsilon(12) = 0
(mu * log)(12) = Lambda(12) = 0
```

Complementary divisor pairs are:

```text
(1,12), (2,6), (3,4)
```

and each is represented by `beta <-> alpha-beta` inside the same valuation box.
