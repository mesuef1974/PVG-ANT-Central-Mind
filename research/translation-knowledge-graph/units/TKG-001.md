## Purpose

## Core concept

The von Mangoldt function is represented simultaneously as:

1. a standard ANT arithmetic function;
2. a Dirichlet-convolution identity;
3. a single-axis prime-power observable in PVG;
4. a dependency node for Chebyshev psi, the zeta logarithmic derivative, and PNT;
5. a governed reasoning benchmark that rejects the false inference from support geometry to asymptotics.

## Reasoning capability

For a positive integer `n`, the executable harness can:

- factor `n`;
- compute valuation-support cardinality;
- decide whether `Lambda(n)` is zero;
- explain the exact ANT ↔ PVG correspondence;
- refuse an unauthorized asymptotic inference.

Example:

```text
n = 72 = 2^3 * 3^2
support cardinality = 2
Lambda(72) = 0
PNT inference = not authorized
```
