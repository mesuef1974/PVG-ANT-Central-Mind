## Purpose

Extend the Translation Knowledge Graph from finite character projectors to the analytic generating object

\[
L(s,\chi)=\sum_{n\ge1}\frac{\chi(n)}{n^s},

## Core identities

For a Dirichlet character modulo `q`, in the absolute-convergence half-plane,

\[
L(s,\chi)=\prod_{p\nmid q}(1-\chi(p)p^{-s})^{-1}.
\]

If `p|q`, then `chi(p^k)=0` for `k>=1`; the local factor is exactly `1`. In PVG this is a labelled axis mask: every prime axis dividing the modulus is deleted by the zero extension.

The logarithmic derivative is

\[
-\frac{L'(s,\chi)}{L(s,\chi)}
=\sum_{n\ge1}\frac{\Lambda(n)\chi(n)}{n^s}
=\sum_p\sum_{k\ge1}\chi(p)^k\log p\,p^{-ks}.
\]

Thus the point `k e_p` receives weight

\[
\log p\,\chi(p)^k,
\]

not `log(p^k) chi(p^k)`.

## Worked modulo-4 examples

For the real nonprincipal character `chi4`:

```text
chi4(n)=0  if n is even
chi4(n)=1  if n=1 mod 4
chi4(n)=-1 if n=3 mod 4
```

Therefore:

```text
n=9=3^2   -> coefficient = +log 3
n=27=3^3  -> coefficient = -log 3
n=8=2^3   -> coefficient = 0 because 2 divides the modulus
n=45      -> coefficient = 0 because 45 is not a prime power
```

For the principal character modulo 4,

\[
L(s,\chi_0)=\zeta(s)(1-2^{-s}),
\]

which explicitly records the removed Euler factor at the bad prime `2`.

## Translation contract

```text
ANT coefficient Lambda(n)chi(n)
-> decode full labelled valuation point
-> require a single-axis point k e_p
-> attach log(p) and phase chi(p)^k
-> annihilate axes p|q
```

The reverse map is exact when the prime labels, exponent, modulus, and character are retained. An anonymized axis pattern cannot recover `chi(p)` or determine whether `p|q`.
