## Purpose

Install a true finite harmonic-analysis layer for arithmetic progressions. The unit separates exact residue projection from the analytic estimates required for prime equidistribution.

## Core objects

- progression sums `psi(x;q,a)`.

## Exact ANT identities

For reduced residues `a,n mod q`,

```text
1_{n congruent a mod q}
= (1/phi(q)) sum_chi conjugate(chi(a)) chi(n).
```

For characters `chi,psi mod q`,

```text
sum_{a mod q, gcd(a,q)=1} chi(a) conjugate(psi(a))
= phi(q) if chi=psi, else 0.
```

Consequently,

```text
psi(x;q,a)
= (1/phi(q)) sum_chi conjugate(chi(a)) psi(x,chi)
```

for reduced `a`, where `psi(x,chi)=sum_{n<=x} Lambda(n)chi(n)`.

## PVG translation

A labelled valuation vector determines the integer exactly. After decoding, reduction modulo `q` places the point in a residue fiber. Character values form a finite phase basis on the reduced residue fibers.

```text
labelled valuation point
-> decoded integer n
-> reduced residue n mod q
-> character spectrum {chi(n)}
-> exact residue-fiber projection
```

This route is exact. It ceases to be exact when axis labels or the integer decoder are removed, because residue modulo `q` is then generally lost.

## Worked example modulo 4

The nonprincipal real character is

```text
chi_4(n)=0 if n is even,
chi_4(n)=1 if n congruent 1 mod 4,
chi_4(n)=-1 if n congruent 3 mod 4.
```

Thus:

```text
chi_4(15)=-1,
chi_4(6)=0,
chi_4(3)chi_4(5)=(-1)(1)=-1=chi_4(15).
```

The two characters modulo 4 give the exact projector onto residues 1 and 3 among odd integers.
