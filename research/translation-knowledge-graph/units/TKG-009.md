## Core objects

For a primitive Dirichlet character `chi` modulo `q`, define the parity bit `a` by

```text
chi(-1)=(-1)^a,  a in {0,1}.
```

The Gauss sum is

```text
tau(chi)=sum_{r mod q} chi(r) exp(2 pi i r/q).
```

For primitive `chi`, its magnitude is `sqrt(q)`. The completed function is

```text
Lambda(s,chi)
=(q/pi)^((s+a)/2) Gamma((s+a)/2)L(s,chi).
```

After analytic continuation, the functional equation routes as

```text
Lambda(s,chi)=epsilon(chi)Lambda(1-s,conjugate chi),
epsilon(chi)=tau(chi)/(i^a sqrt(q)).
```

## Worked primitive example: chi4

For the real primitive character modulo 4,

```text
chi4(1)=1
chi4(3)=-1
chi4(even)=0
chi4(-1)=-1
```

so `a=1`. Its Gauss sum is

```text
tau(chi4)=2i,
```

and therefore

```text
epsilon(chi4)=2i/(i*2)=1.
```

The completed function is

```text
Lambda(s,chi4)
=(4/pi)^((s+1)/2) Gamma((s+1)/2)L(s,chi4),
```

with functional-equation route

```text
Lambda(s,chi4)=Lambda(1-s,chi4).
```

This routing statement presupposes the analytic theory; it is not derived from a finite numerical comparison.

## What is not obtained

```text

```
