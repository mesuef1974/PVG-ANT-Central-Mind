# PVG Pareto Explorer 3D

صفحة ويب محلية مستقلة ثلاثية الأبعاد لعرض المستوى

\[
P=\{2,3,5\},\qquad \Omega=6
\]

وجبهة باريتو الناتجة عن تعظيم الأهداف:

\[
\left(n,\tau(n),\frac{\sigma(n)}n,\frac{\varphi(n)}n\right).
\]

## التشغيل

من PowerShell داخل الـworktree المنفصل:

```powershell
cd "D:\PVG-ANT-Inverse-Geometry-001"
powershell -ExecutionPolicy Bypass -File tools\open_pvg_pareto_explorer.ps1
```

أو افتح الملف مباشرة:

```powershell
Start-Process "D:\PVG-ANT-Inverse-Geometry-001\web\pvg-pareto-explorer\index.html"
```

الصفحة محلية وذاتية الاكتفاء، ولا تحتاج إلى npm أو مكتبات JavaScript أو خادم ويب.

## التحكم ثلاثي الأبعاد

- السحب بالزر الأساسي: تدوير المشهد.
- `Shift + سحب`: تحريك الكاميرا أفقيًا ورأسيًا.
- عجلة الفأرة: التكبير والتصغير.
- النقر على نقطة: تثبيت تفاصيلها.
- خيار `الارتفاع`: يحدد الدالة التي تصنع التضاريس الرأسية.
- خيار `لون النقطة`: مستقل عن الارتفاع، ويسمح بمقارنة حقلين في المشهد نفسه.
- يمكن التبديل بين المنظور والإسقاط المتعامد، وتفعيل التدوير التلقائي.

## تحسين القراءة

تظهر الأعداد داخل شارات داكنة مستقلة عن لون النقاط، بنص أبيض وحدود عالية التباين. لذلك تبقى التسميات مقروءة حتى فوق النقاط الفاتحة أو عند اختيار تدرجات لونية حسابية.

## ما تعرضه الصفحة

- جميع نقاط المستوى الـ28 داخل المثلث الشبكي.
- جبهة باريتو العالمية ذات 19 نقطة.
- حواف الجبهة الـ27 ومكوناتها الثلاثة.
- الجسور، ونقاط القطع، والنقطتان المعزولتان.
- قمم الأهداف الفردية.
- تضاريس ثلاثية الأبعاد لـ `log n` و`tau` و`sigma(n)/n` و`phi(n)/n`.
- تفاصيل حسابية وهندسية عند المرور والنقر على أي نقطة.

## الحد العلمي

هذا عارض بصري لتحليل منتهٍ دقيق على وجه ومستوى محددين. لا يثبت قانونًا تقاربيًا، ولا يمنح جبهة باريتو معنىً مطلقًا مستقلًا عن قائمة الأهداف المختارة.
