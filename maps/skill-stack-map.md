## Axis-addition authority chain

For a sum problem, the Central Mind must route through:

```text
integer addition relation
-> exact ordered fiber
-> valuation transport
-> weighted observable
-> residue/Fourier channel
-> rank or analytic certificate
-> honest classification
```

It must not replace this route with `nu(x)+nu(y)=nu(x+y)`.
