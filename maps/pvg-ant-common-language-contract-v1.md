# PVG–ANT Common Language Contract v1

**Status:** governing translation interface  
**Classification:** Diagnostic / Language Infrastructure  
**Scope:** unify knowledge activation, native PVG objects, ANT routing, information loss, and certificates without adding new translation cards.

## 1. Purpose

The Central Mind needs more than a vocabulary list. It needs one repeatable sentence form in which PVG and analytic number theory can describe the same problem without erasing hypotheses, labels, phases, scales, or certificates.

The governing rule is `RULE-KNOWLEDGE-TO-TRANSLATION-001`:

> Knowledge becomes part of the Central Mind only when it is normalized into a source-grounded PVG–ANT translation with explicit morphisms, preserved and lost information, tool compatibility, reverse conditions, and a test or certificate.

## 2. Canonical translation record

Every operational bridge, reasoning step, or knowledge-return packet answers these fields in order:

```text
1. Named task
2. Source-grounded ANT statement or object
3. Hypotheses, normalization, range, and uniformity
4. Native PVG object
5. Forward morphism or projection
6. Information preserved
7. Information lost and LOSS level
8. ANT image after translation
9. Compatible analytic tools
10. Main term / expected output
11. Error term, wall, or missing certificate
12. Reverse translation and exact recovery conditions
13. Counterexample to an invalid reverse inference
14. PVG materiality result
15. Verification or finite witness
16. Honest classification and source
```

A record is incomplete if it offers only an analogy, a visual resemblance, or a theorem name.

## 3. Shared grammar

The common sentence form is:

```text
Under hypotheses H and normalization N,
PVG object P is sent by admissible morphism M to ANT object A.
The map preserves I+ and loses I− at LOSS-k.
Tool T may act on A in range U and returns output O with error E.
The reverse A → P is valid only under recovery certificate R;
without R, counterexample X blocks the inference.
PVG is material / non-material / not-yet-tested because of ablation result B.
```

This grammar is the bridge between source knowledge and executable reasoning.

## 4. Three synchronized views

Every active problem is maintained in three views.

### PVG view

- valuation vector, support, height profile, divisor box, face/margin, residue fiber, local prime-axis germ, convolution polytope, or another registered object;
- labels and exact data retained or explicitly forgotten;
- admissible morphisms composed from the ontology.

### ANT view

- multiplicative function, Bell series, Euler product, Dirichlet series, character decomposition, Mellin/Perron transform, sieve sequence, convolution, mean value, limiting law, or another source-grounded object;
- exact hypotheses, ranges, and error terms;
- compatible theorem/tool and known limitations.

### Certificate view

- identity, known theorem, reinterpretation, diagnostic, boundary, open problem, candidate mechanism, or new theorem;
- reconstruction certificate or named information loss;
- analytic certificate or wall;
- source, finite witness, benchmark evidence, formal check, or external review.

No view may silently substitute for another.

## 5. Knowledge activation route

```text
named task
→ prerequisite gap map
→ minimum trusted source extraction
→ exact ANT normalization
→ native PVG object selection
→ morphism and loss audit
→ analytic routing
→ proof/test/negative certificate
→ common-language record
→ maturation receipt
→ reusable return to the Central Mind
```

Knowledge that stops before the common-language record remains available or extracted, not operationally ready.

## 6. Translation directions

### ANT → PVG

Ask:

1. What multiplicative/local structure is present?
2. Which prime labels and exponent heights matter?
3. What native PVG object represents the data exactly?
4. Which projection is being applied?
5. What analytic information disappears under that projection?

### PVG → ANT

Ask:

1. Is the PVG observable multiplicative, additive, local, aggregate, or phase-sensitive?
2. What Bell/Euler/Dirichlet/Fourier/sieve/convolution object does it induce?
3. Which theorem applies with the exact normalization and range?
4. What certificate is still missing for a global or reverse claim?
5. Does ablation show PVG materiality or only reinterpretation?

## 7. Composition discipline

A multi-step translation is valid only if adjacent codomain/domain types match and the cumulative loss is recorded.

```text
P0 --M1--> P1 --M2--> A1 --T--> A2
```

The final reverse claim may use only information preserved by every preceding map. A later analytic theorem cannot restore labels, phase, localization, or pointwise data that an earlier projection destroyed unless a separate recovery certificate is supplied.

## 8. Knowledge-growth discipline

Knowledge acquisition should grow in response to:

- an active theorem prerequisite;
- a benchmark failure cluster;
- an unresolved source or priority question;
- a newly named wall;
- a failed reverse translation;
- a missing uniformity or error-term certificate.

It should not grow merely because another book or tool is available.

## 9. Benchmark 002 firewall

This contract changes the form of reasoning, not the hidden answers. Before the raw Benchmark 002 baseline:

- no new translation cards;
- no gold-key exposure;
- no targeted learning from hidden cases;
- no proof-pattern additions derived from the held-out set.

After the immutable error map, knowledge packets and translation additions may be created only for named failure clusters.

## 10. Scientific ceiling

A complete common-language record can certify a correct translation or expose a missing certificate. It cannot certify originality or theoremhood without the separate literature, proof, and external-validation gates.
