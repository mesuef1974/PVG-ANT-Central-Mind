# What Not To Import

## Do not import
- PDF books.
- raw copyrighted text.
- full skill prompt dumps.
- unverified claims.
- copied theorem lists without transformation.
- numerical experiments as proofs.
- any RH/GRH progress language.

## Import only
- transformed skill cards (interface cards).
- diagnostic summaries.
- theorem / tool cards.
- PVG rules.
- certificate statuses.
- missing certificate records.

## لماذا

العقلُ يتراكم بالتحويل لا بالنسخ. الكتابُ يدخل كأدواتٍ وقواعدَ وشهادات؛ المهارةُ تدخل كبطاقةِ واجهة؛ التجربةُ تدخل كـ evidence لا مبرهنة. هذا الفصلُ هو ما يمنع «مجلّدًا يتضخّم ثمّ ينهار». يفرضه `tools/no_pdf_audit.py` (لا PDF متعقَّب) و`honesty_audit.py` (لا لغةَ تقدّم).
