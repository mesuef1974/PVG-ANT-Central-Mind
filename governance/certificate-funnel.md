# Certificate Funnel

أي فكرة تمر عبر هذا القمع؛ لا قفزَ فوق مرحلة.

```text
Observation → Pattern → Diagnostic → Candidate Mechanism → Lemma → Theorem → Audited Result
```

| المرحلة | التعريف | لا يسمح بـ |
|---|---|---|
| Observation | ملاحظة أولية | ادّعاء قوي |
| Pattern | نمط متكرر | برهان |
| Diagnostic | أداة فهم/كشف | نتيجة |
| Candidate Mechanism | آلية مرشحة | نظرية؛ يحتاج: ما الجديد؟ أين يفشل المعروف؟ ما الشهادة المطلوبة؟ ما الاختبار القابل للإبطال؟ |
| Lemma | قضية محلية مثبتة | — (برهان واضح) |
| Theorem | نتيجة كاملة | — (برهان + شهادة) |
| Audited Result | خضعت للتدقيق | نشر بلا source/claim/proof/no-overclaim audit |

**Honest classification:** Governance / Diagnostic. No RH/GRH progress.
