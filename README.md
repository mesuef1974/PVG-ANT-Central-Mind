\[

```text

2 not in F ⇔ N is odd; R_2(N) is empty or {{2,N-2}}.
```

For each representation define the centered-gap coordinate

\[
\Delta=q-p.
\]

\[

\qquad
q=\frac{N+\Delta}{2}.
\]

Exact identities:

\[
\Delta\equiv N\pmod2,
\qquad
N^2-\Delta^2=4pq,
\qquad
\gcd(N,\Delta)=\gcd(N,2).
\]

For even \(N\), \(m=N/2\) and \(d=\Delta/2\) satisfy

\[
p=m-d,
\qquad
q=m+d,
\qquad
m^2-d^2=pq,
\qquad
\gcd(m,d)=1.
\]
