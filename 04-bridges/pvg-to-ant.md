# PVG → ANT Dictionary

قاموسُ الترجمة بين لغة هندسة التقييمات الأولية (PVG) والأدوات التحليليّة (ANT). الغرض: أن يترجم العقلُ بين اللغتين دون أن يخلط بينهما، ودون أن يعامل الترجمةَ كبرهان.

| PVG (هندسة) | ANT (تحليل) | ملاحظة الحدّ |
|---|---|---|
| support | `ω(n)`, الطبقةُ الخاليةُ من المربّعات (squarefree) | وصفٌ لا شهادة |
| height | `Ω(n)`, قوى الأوّليّات | — |
| phase | `μ, λ, χ, n^{it}` | الطورُ يُختبَر (Halász) قبل ادّعاء الإلغاء |
| divisor box | `d(n), τ_k(n)` | طريقةُ القطع الزائد |
| residue fiber | شخصيّاتُ Dirichlet، المتتاليّاتُ الحسابيّة | تعامدٌ يُقطِّر الشرطَ التطابقيّ |
| edge | الترتيبُ الأقصى (maximal order) | — |
| tail | الانحرافاتُ الكبيرة (large deviations) | — |
| local factor | حاصلُ Euler | المحاورُ الصحيحة: primes / prime powers / prime ideals / Frobenius |
| global transfer | Tauberian / Perron / Selberg–Delange | لا معدّلَ من Tauberian الصرف |

## قواعد الجسر (حدود الترجمة)

1. الترجمةُ تنويرٌ لا برهان: كلُّ صفٍّ تصنيفُه الأقصى **Reinterpretation**.
2. `residue → spectral` تكلفتُه بمستوى GRH — لا يُعبَر مجّانًا (pvg-zeta-observables-layers).
3. إعادةُ التسمية الهندسيّة **لا تعوّض** zero-control (PVG transfer rule 6).
4. لا مرصودَ PVG بلا سلسلة Dirichlet مقابلة أو تفسيرِ غيابها (rule 1).

**Honest classification:** Reinterpretation / Diagnostic. No RH/GRH progress.
