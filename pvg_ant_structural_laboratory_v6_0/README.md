# PVG–ANT Structural Laboratory v6.0

External research application package. The canonical repository keeps validation code, registries, certificates, and hashes; the HTML application remains external under repository policy.

## Run

```bash
python -m http.server 8000
# open http://localhost:8000
```

## Modules

- `src/legacy-app.js`: preserved v5.5 explorer and smooth-number laboratory.
- `src/core/arithmetic.js`: exact arithmetic/PVG core.
- `src/core/smooth.js`: independent smooth-number grid and saddle diagnostics.
- `src/core/statistics.js`: calibration, partial correlations, counterexamples.
- `src/core/additive.js`: additive fibers, residue channels, finite Fourier transform.
- `src/app.js`: v6 UI integration.

## Scientific ceiling

Exact finite identities and computational diagnostics only. No global error theorem, Goldbach proof, RH/GRH progress, or originality claim.
